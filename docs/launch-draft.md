> CipherShape compiles small numerical endpoints into an OpenFHE CKKS protocol:
> clients encrypt their inputs, a separate server evaluates ciphertexts, and
> clients decrypt the allowed outputs. The included examples cover multi-output
> statistics and a public linear model trained on synthetic data.
>
> The engineering question is deployment cost. How should a workload trade
> rotation-key setup and upload against online rotations, shared intermediates
> and live memory? The bounded planner searches these choices together, with
> explicit security and numerical-error contracts.
>
> This is an unaudited research implementation for an honest-but-curious server.
> It has fixed shapes and depth, public weights, visible timing/size metadata and
> no plaintext fallback. The study keeps plaintext overhead, approximation error,
> encryption error and model task error separate. It makes no universal speedup
> claim or matched external-compiler performance claim.
>
> Source and reproduction instructions: https://github.com/nazeeh111/CipherShape
